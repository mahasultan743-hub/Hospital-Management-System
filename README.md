# Hospital Management System (C++)

A console-based OOP project for managing hospital records:
Patients • Doctors • Appointments • Billing

## Build
g++ Hospital_management_system.cpp -o hospital

## Run
./hospital

## Data Files (auto-created)
patient.txt, doctor.txt, appointment.txt, billing.txt

## Features
✅ Add/View/Search/Update/Delete Patients
✅ Add/View/Search Doctors
✅ Book/View/Cancel Appointments
✅ Generate/View Bills

## Concepts
Inheritance • Encapsulation • File Handling • Menu-Driven Design
